# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this repository starts its public
history at the first Git release of the `pfp-public` staging project.

## [0.1.0] - 2026-05-09

### Added

- Initial public repository root pack for Product Feed Protocol (PFP).
- Root legal and ownership artifacts: `LICENSE`, `THIRD_PARTY_NOTICES`, and
  `MAINTAINERS`.
- PFP-specific root `README.md` with public onboarding narrative and quickstart.
- `py.typed` markers for `pfp_core`, `pfp_runtime`, and `pfp_utils`.

### Changed

- Cleaned `pyproject.toml` metadata for public distribution.
- Explicitly fixed package root exports for `pfp_core`, `pfp_runtime`, and
  `pfp_utils`.

### Notes

- This release is intended for public Git distribution.
- PyPI publishing is intentionally out of scope for this phase.
