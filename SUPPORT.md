# Support & Professional Services

## Community Support (Free)
As an open-source project, PFP is maintained by an independent developer. Community support is provided on a **best-effort** basis. 

If you encounter a bug or have a feature request, please open an issue in the repository issue tracker.
* **SLA:** None. Issues are reviewed when time permits.
* **Expectation:** Please provide detailed context, logs, and a minimal reproducible example (or Golden YAML) to help speed up the review.
